# onsombl – adding knowledge

Drop `.md` files into the `knowledge/` folder (edit on GitHub: Add file → Create new file). The chat reads them and cites the ones it uses.

Each file starts with a short header:

```
---
title: Playlist pitching guide
source: where it came from (your own notes, a link, etc.)
type: playbook        (playbook, benchmark or news)
tags: playlists, curators, pitch
---
The content, in plain text or markdown.
```

- Titles and tags help the right document get picked, so use words people would ask about.
- Keep each file focused: one topic, under about 600 words.
- **This repository is public.** Only add content you wrote or have the right to share. For articles and reports you don't own, write a short summary in your own words and link to the original. Do not paste them in full.
